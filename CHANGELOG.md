# Changelog

## 0.2.0 - 2026-08-11

- Add the versioned `SceneDefinition` contract and JSON Schema.
- Discover, parse, validate, resolve, normalize, and index SceneDefinition 2.0 YAML scenes.
- Move all T113 knowledge, placement, labels, views, journeys, function contracts, and display defaults into one YAML scene.
- Route the default URL and `?scene=` through the same enhanced Explorer and declarative 3D renderer.
- Remove the obsolete simplified renderer and legacy T113 hard-coded runtime data.
- Add AI scene-authoring guidance and the structurally different NVMe Bitmap example.
- Add relational validation for duplicate IDs, dangling references, ownership disagreement, and missing layouts.

## 0.1.0 - 2026-08-10

- Publish the evidence-aware 3D topology framework.
- Include the anonymized T113 ARM-XVC reference scene.
- Add distance LOD, collision-resolved labels, focus framing, causal journeys, and bilingual UI.
- Add static GitHub Pages deployment and open-source governance files.
