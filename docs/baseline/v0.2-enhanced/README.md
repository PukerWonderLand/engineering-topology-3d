# T113 增强型黄金基线

本目录冻结 `SceneDefinition 2.0` 迁移前的增强型 T113 ARM-XVC 页面。迁移期间，页面能够打开不等于功能保持；必须同时满足本文件与 `docs/feature-preservation-checklist.md`。

## 基线画面

- `overview-zh.png`：中文物理全景。
- `overview-en.png`：英文物理全景。
- `focus-module-zh.png`：`openFPGALoader XVC A · 10200` 模块的 100% 聚焦模式。

## 数据基线

- 17 个增强型节点。
- 36 条增强型边。
- 3 条主通道：`KU15P`、`X690T`、`HEALTH`。
- 6 个视图：`overview`、`host`、`fpga`、`c2s`、`s2c`、`spu`。
- 5 条黄金旅程：`send`、`receive`、`init`、`wait`、`remove`。
- 4 个因果层：`payload`、`control`、`sync`、`lifecycle`。
- 7 类执行上下文和 9 类事务关系。

## 13 个持久化显示参数

| 参数 | 默认值 | 允许范围 |
|---|---:|---:|
| 主通道粗细 | 4.5 | 1–6 |
| HUD 前方距离 | 1.2 | 0.6–2.4 |
| 模块标签距离 | 1.2 | 0.6–2.4 |
| 标签布局模式 | module | module / camera |
| 标签连接线粗细 | 1.5 | 0.5–6 |
| 模块标签大小 | 1.0 | 0.6–1.6 |
| 聚焦批注大小 | 1.0 | 0.6–1.6 |
| 聚焦 HUD 字体 | 1.0 | 0.8–1.8 |
| 子标签显示距离 | 30 | 10–70 |
| 子标签淡出区间 | 8 | 2–20 |
| 远景淡出起点 | 48 | 15–100 |
| 最远板块不透明度 | 0.22 | 0.08–0.8 |
| 最远数据流不透明度 | 0.55 | 0–1 |

所有持久化键必须使用场景 ID 作为命名空间，避免多个 YAML 场景互相污染设置。

## 验收要求

1. T113 YAML 编译后的节点、边、旅程、函数及 ID 集合必须与迁移前一致。
2. 中文与英文都必须保留相同的信息结构。
3. 全景、模块聚焦、标签碰撞、距离 LOD、数据动画和全部滑块不得降级。
4. 第二个领域场景只能新增 `examples/<scene-id>/topology.yaml`，不得修改 `src/` 或 CSS。
