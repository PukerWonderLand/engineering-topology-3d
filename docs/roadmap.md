# Roadmap

- Extract all reference-specific placement from the renderer.
- Define a versioned topology schema and validation pipeline.
- Load multiple examples without rebuilding the framework.
- Add evidence citations and source inventory links at node and edge level.
- Add deterministic screenshot regression checks for representative cameras.
- Package reusable camera, LOD, label-layout, and causal-journey primitives.

The v0.1 boundary is deliberate: the visualization mechanics are reusable, while the bundled T113 scene remains the reference implementation rather than a fully generic importer.
