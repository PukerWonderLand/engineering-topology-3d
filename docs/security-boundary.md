# Security boundary

This repository is a static visualization project. It contains no remote-control backend and must not be treated as an operational console.

Public examples must exclude credentials, private keys, real network addresses, cable serial numbers, proprietary bitstreams, flash images, internal logs, and production SOPs. XVC itself has no built-in authentication or encryption; any real deployment belongs behind a trusted network, VPN, ACL, or authenticated tunnel.

Report repository vulnerabilities through GitHub's private security advisory flow. Do not include live secrets, customer data, or exploitable production addresses in an issue.
